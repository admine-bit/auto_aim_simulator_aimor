## 边界

不得放入个人偏好、本机绝对路径、原始聊天、task manifest、构建日志、临时数据、Token/密码/证书、完整设备编号或未经验证的猜测。个人和临时内容放在仓库外的项目私有工作区：

`<workspace-root>/.agent-projects/imca_vision_26aim/`

## 状态

- 候选：任务中发现，尚未根据最终代码确认。
- 有效：有当前代码、测试或明确规则作为证据。
- 待核实：相关代码变化或超过复核时间，使用前必须重新检查。
- 已归档：已被新方案替代，仅保留历史原因。

## 发布

从私有工作区发布前，使用项目 Skill `project-knowledge-publish` 扫描敏感信息、个人路径、临时内容、重复文档和代码引用，展示完整 Git diff，等待用户确认后再提交或推送。
