# w 估计调试复盘（2026-07-23 ~ 07-24，已全部回退）

本轮针对"卡尔曼输出的 w 周期性波动、极差 140°/s、正方形车 l 漂到 10cm"做了一轮诊断和五处改动，
最终稳态波动没有改善，还引入了捕获瞬间 w 俯冲的新问题，所有代码改动已回退。
本文记录：哪些诊断结论是可靠的（数据支撑，回退不影响其成立）、五处改动各自的结果、
失败的根本原因、以及下一次尝试应该怎么做。

---

## 一、经数据确认的事实（这些结论仍然成立）

这些结论都有回放波形支撑，与代码改动无关，是本轮最有价值的产出：

1. **监控错了信号**。`data["real_yaw"] = target_yaw` 记录的是 `ypd[0]`（视线角），
   不是驱动 w 的观测。真正喂给 EKF 相位的观测是 `z[3] = ypr_in_world[0]`
   （optimize_yaw 搜索后的装甲板朝向角），此前从未被画出来过。
   "识别 yaw 很正常所以 w 不该跳"的前提从一开始就不成立。

2. **z[3] 里存在 ±60°~±100° 的镜像翻转方波**（armor_yaw / yaw_raw 键的波形）。
   来源是 PnP/IPPE 的镜像双解：接近正对时 +θ 与 −θ 两个解的重投影误差几乎相同，
   optimize_yaw 的 1° 网格像素代价分不开它们，落在哪边看噪声。
   optimize_yaw 之后（红线）大部分时间跟着原始值（绿线）一起翻，修正尖峰（30 号键 −40~−70°）零星出现。

3. **旧关联打分会被翻转帧偷走 ID**。打分是 `|朝向误差| + |视线误差|`，朝向项占绝对权重；
   +45° 的板翻成 −45° 后朝向恰好像隔壁板（朝向差 90° vs 视线差仅 4~8°），
   翻转帧被系统性配错 id。波形证据：last_id 序列 3→2→**跳过1**→0，id=1 象限整段消失。

4. **l 漂到 10cm 的机理是"唯一没人管的自由参数吸收系统性残差"**。
   距离观测被 `R_dig[2] ≥ 1 m²` 实质禁用，朝向观测 σ 大也帮不上，
   真实 l=0 没有告诉滤波器——系统性残差就把 l 慢慢挤歪。
   给 l 很小的过程噪声只能放慢速度，挡不住单向挤压（小 Q ≠ 锚）。

5. **w 的均值没有问题**。x[6] 相位锯齿的斜率 = w 均值 = id 停留时间反推的真实转速，
   三者一致，相位无滑移。问题只在波动，波动周期 = 1/4 圈（切板周期）。

6. **切断视线→相位耦合（`H.block(0,6,3,1).setZero()`）对 w 波形无影响**。
   说明 1/4 圈周期的偏差同时存在于视线通道和朝向通道（同一块板、同一套坐标变换），
   切一条另一条照供。

7. **转速减半时波动"显得"更糟是正常现象**：偏差导数成分随转速线性下降，
   噪声追逐成分与转速无关，低速下后者相对占比翻倍。不同转速的录像不能直接比幅度。

8. **子弹飞行 ~0.4s ≈ 一个波动周期**，1/4 圈周期的 w 波动在飞行时间积分里大部分抵消。
   对命中率真正危险的是相位飞转、ID 配错、l 失真，而不是 w 波形本身好不好看。
   KPI 应该是 planner 瞄准点的稳定性，w 只是中间量。

## 二、五处改动与各自结果

| # | 改动 | 结果 |
|---|------|------|
| 1 | 朝向创新门控（残差>35° 时 R[3]×100） | **引入捕获俯冲**（w 冲到 −3000°/s 锁死 ~1s），后补逃生仍残留 −1200°/s 瞬态 |
| 2 | 关联打分改位置距离为主 + 朝向 20° 上限 + last_id 迟滞 | **有效**：id 序列恢复干净的 3→2→1→0，id=1 象限回来了；但对 w 波动无改善 |
| 3 | lock_l（P0[9]=0 冻结 l） | l 不再漂；对 w 波动无改善 |
| 4 | R[3] 视角自适应（σ=0.07/sin(视角)） | 对 w 波动无改善 → 反证波动主源是**斜视区的系统性偏差**，不是正对区噪声 |
| 5 | optimize_yaw 谷底抛物线插值 | 无可见改善（1° 量化不是主要噪声成分） |

同速对比：改前 ±40 @ 均值200°/s，改后 ±45 @ 均值218°/s——相对波动 20% 持平。

### 捕获俯冲的成因链（改动 1 的教训核心）

```
初始化恰好落在镜像分支（第一帧 ypr[0] 是翻转值）
→ P0[7]=100（σ_w=10rad/s，无物理依据）允许初期把相位矛盾大量灌给 w
→ 相位开始飞转后，位置关联总能匹配到"正在扫过"的槽位，不报错
→ 此后每帧朝向残差都 >35°，门控持续拒绝纠正 —— 自锁
→ 维持约 1 秒，直到 NIS 检测强制打回 lost
```

门控逃生（连续 30 帧被拒则放行）+ 物理钳位（|w|≤8rad/s）+ P0[7]=25 三刀之后
俯冲缩短变浅（−1200°/s、~0.3s）但未根除——因为根子在初始化落在坏分支，
后面全是补丁摞补丁。

## 三、失败的根本原因

1. **在滤波层修测量层的病**。证据链（视角相关、切通道无效、σ 调整无效）早就指向
   测量本身有系统性偏差（镜像双解 + 固定 15° 俯仰假设 + 云台外参），
   而偏差不是噪声——调 R、调 Q、加门控都滤不掉有偏测量。
   五处改动有四处在滤波/关联层打转。

2. **门控类机制天生带自锁风险，事后补逃生是本末倒置**。
   任何"根据估计值拒绝观测"的机制，从第一天就必须三件套齐全：
   物理界限钳位、连续拒绝逃生、收敛前禁用。缺一个就可能把一次坏初始化锁成持续故障。

3. **一次上车太多变量**。门控、关联、锁 l、视角 R、插值几乎同批上车，
   回放变差时无法归因，只能整体回退，前面有效的部分（关联修复）也一起陪葬。
   正确节奏：一次一个变量、同速录像、固定基准对比。

4. **忽视了参数生态的隐性耦合**。P0[7]=100 在旧配置（朝向 σ≈54°，几乎不信）下无害，
   但配合 R[3]=9e-2（σ≈17°）+ 门控后变成俯冲的放大器。
   动一个参数前要问：它现在无害，是不是因为别的参数在掩护它。

5. **测试矩阵缺"捕获瞬态"用例**。所有回放都盯稳态波形，
   初始化/re-acquire 路径没有专门用例，问题上车才暴露。

6. **过度承诺**。"预期波动大幅收窄"说了两次都没兑现。
   对没有做过归因实验的改动，不应该给出量化预期。

## 四、如果下次再战，按这个顺序

1. **先画偏差曲线，再动代码**：记录每帧 `yaw_innov`（朝向残差）对 `视角` 的散点。
   大视角处 innov 均值非零、符号随视角翻 → 系统性偏差实锤，
   源头是固定 15° 俯仰假设 / 云台 pitch-roll 外参 → **去校准，不改滤波**。

2. **修测量：optimize_yaw 镜像消歧**。平底谷里两个镜像解需要外部信息才能选边：
   时间连续性先验（上一帧结果）或 EKF 预测角做 tiebreaker，
   权重只够在平底谷选边、不足以扭曲清晰谷底。

3. **恢复距离观测**。`R_dig[2] ≥ 1 m²` 等于没有距离信息，这是 r/l 无锚、
   系统性残差四处流窜的土壤。按视角/距离给它一个真实的噪声模型。

4. **关联修复可以单独重新上车**（本轮唯一被数据证明有效的改动）：
   位置距离为主 + 朝向误差上限。单变量上车，用 id 序列验收。

5. **每一步的验收标准提前写死**：id 序列干净、l 稳定、相位斜率=均值守恒、
   转速突变响应不劣化（红线）、**捕获瞬间无俯冲**（新增用例）、
   planner 瞄准点稳定性（最终 KPI）。

## 五、留下的调试工具（可复用）

- 日志键位：`last_id` / `matched_armor_num` / `armor_yaw` / `armor_yaw_raw` /
  `yaw_opt_correction` / `phase(x[6])` / `w(x[7])` —— 一帧固定键数，PlotJuggler 直接看。
- 守恒检查：x[6] 锯齿斜率 ≟ w 均值 ≟ 360°/(id 停留×4)，三者不等 = 相位滑移。
- 归因手法：同一段录像、单变量开关（如 H.block 一行、R 一个数）、对比波形。
- 判读表：波动周期 = 1/4 圈 → 视角相关偏差；= 1/2 圈 → l/奇偶性；= 整圈 → 世界系/标定。
