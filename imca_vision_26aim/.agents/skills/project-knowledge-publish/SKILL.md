# Project Knowledge Publish

## 适用范围

只处理项目私有工作区中准备发布的知识候选。默认工作区为：

`<workspace-root>/.agent-projects/imca_vision_26aim/`

共享内容只能发布到当前项目仓库的 `docs/ai/` 或 `.agents/skills/`。

## 流程

1. 读取候选内容及其来源，区分 `candidate`、`valid`、`needs-review` 和 `archived`。
2. 扫描 Token、密码、私钥、证书、个人绝对路径、完整设备编号、账号状态、原始聊天、日志、临时图片/数据和未验证猜测。
3. 将本机绝对路径改写为仓库相对表达，例如 `<repo-root>/tasks/auto_aim`。
4. 用 `rg` 检查代码路径、命令、文档链接和现有权威文档；发现冲突时标记，不猜测原因。
5. 只根据 `final` 代码整理团队文档或项目 Skill；若代码被人工调整或删除，重新核对候选内容。
6. 运行与内容相关的静态检查或测试，并记录版本、命令、结果和环境限制。
7. 展示完整 `git diff` 和待发布文件，等待用户明确确认。
8. 未经用户再次明确授权，不执行 `git commit`、`git push`、创建 MR 或删除私有原始资料。

## 输出检查清单

- [ ] 没有个人信息、秘密、完整设备标识或本机绝对路径
- [ ] 内容对团队有长期复用价值
- [ ] 代码路径、命令和链接已检查
- [ ] 没有与现有权威文档冲突，或冲突已明确标记
- [ ] 内容依据最终代码，而不是仅依据 Agent 初稿
- [ ] 验证命令和限制已记录
- [ ] 完整 Git diff 已展示并等待用户确认
