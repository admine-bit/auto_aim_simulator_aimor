# 仿真器协作规则

- 联调未解决问题统一维护在 `../未解决问题清单.md`；遵循根目录 `../AGENTS.md` 的列举、更新、关闭及重开规则，不建立平行清单。
- 默认使用 `start_legacy_vision.sh` 启动仿真和视觉程序，只有用户明确指定其他入口时才切换。
- 能量机关的旋转方向和角速度是固定约束。除非用户明确要求更改，不能修改 `src/robomaster/power_rune/rotation.rs` 中的方向、速度及其生成逻辑，也不能修改 `construct.rs` 中已固定的红蓝符转向关系。
- 调整能量机关亮灯或材质时，只改视觉状态，并检查旋转逻辑未受影响。
- 中心 R 标保持常亮、固定不随符叶转动；字形朝向沿用 `construct.rs` 中经用户校正的固定角度。
